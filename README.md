> **Praxis 2.0 · GDG GB Pant · Problem Statement 2: Pricing Strategy & Demand Trade-off Exploration**

---

## 🎯 Problem Statement & Motivation

Pricing decisions in e-commerce are overwhelmingly made on gut feeling. Sellers and category managers lack visibility into **price elasticity**, optimal discount levels, and the **demand-revenue trade-off** for their products.

**PriceIQ** solves this. It's a full-stack Pricing Intelligence Platform that lets analysts:

- 🎚️ **Simulate** pricing decisions with a live price slider
- 📈 **Visualize** the demand-revenue curve generated by a trained ML model
- 🤖 **Read** AI-generated strategic recommendations tailored to the exact scenario
- 🏪 **Compare** product categories, sub-categories, and competitor positioning

| `discounted_price` | Selling price (₹, string) |

| `about_product` | Feature bullet points |
| `review_title`, `review_content` | User review text |
| `img_link`, `product_link` | Product URLs |

## 🤖 ML Integration

- **Model:** Random Forest Regressor (scikit-learn, 200 trees, max_depth=15)
- **Features:** `discounted_price`, `actual_price`, `discount_percentage`, `rating`, `discount_amount`, `price_ratio`, + one-hot encoded top-level `category`
- **Target:** `rating_count` (demand proxy — higher ratings count ≈ higher sales volume)
- **Train/Test:** 80/20 split, R² and RMSE printed on startup
- **Elasticity:** Derived empirically — model runs at `base_price` and `base_price × 1.1`, computes `% Δ demand / % Δ price`
- **Optimal Price:** Grid search over the category price range maximizing `price × predicted_demand`

## 🧠 GenAI Integration

The strategy engine analyzes four dimensions per simulation:

1. **Margin Health** — current margin vs 25% industry benchmark
2. **Elasticity Regime** — is this category elastic or inelastic?
3. **Gap to Optimal** — magnitude and direction of current vs model-optimal price
4. **Competitor Context** — how does current price compare to category average?

**Output:** A structured narrative with:
- `headline` — one bold strategic statement
- `insights` — 4 data-driven insight strings referencing actual numbers
- `tags` — 3–4 dynamic hashtags
- `recommendation` — one actionable sentence

**Implementation:**
- **Option A (default):** Rule-based Python engine — works offline, no API key needed
- **Option B:** Google Gemini API — builds a prompt with all numeric inputs, parses JSON response. Falls back to Option A on failure.

Updates live on every price/parameter change.

## 🚀 How to Run

```bash
# 1. Clone and navigate
cd priceiq

# 2. Create & activate virtual environment
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Ensure dataset is in backend/
# Pricing_dataset.csv should already be in backend/

# 5. Start backend
cd backend
uvicorn app:app --reload --port 8000

# 6. Open frontend/index.html in your browser
# That's it!
```

> **Note:** The model trains on startup (~5-10 seconds). You'll see R² and RMSE printed in the terminal.

> If the backend is offline, the frontend automatically switches to **demo mode** with mock data — the UI still looks and works perfectly.

## ⚖️ Ethical Considerations

- **Consumer protection:** The model includes a cost-floor guardrail — it never recommends prices below cost, preventing predatory pricing strategies
- **Transparency:** All recommendations show the data and logic behind them. No black-box outputs — every insight references actual numbers
- **Dataset bias:** This is Amazon India product data from select categories. Generalization to other platforms or markets requires retraining
- **Rating count as demand proxy:** Rating count correlates with but is not identical to actual sales. The model's predictions should be interpreted as relative demand signals, not absolute unit sales
